# Security Policy

## Supported versions

Only the latest release receives security fixes.

| Version | Supported |
|---|---|
| 2.0.x | Yes |
| < 2.0 | No |

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately through GitHub instead: go to the [Security tab](https://github.com/metalinked/laravel-defender/security) of this repository and click **Report a vulnerability**.

Include, if possible:

- The package, Laravel and PHP versions affected.
- Steps to reproduce, or a proof of concept.
- The impact you expect.

You should get a first answer within a few days. Once the issue is confirmed, a fixed release will be published and you will be credited in the advisory unless you prefer otherwise.
